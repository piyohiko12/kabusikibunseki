# 米国株式分析ツール

Streamlit製の米国株分析ダッシュボードです。株価・財務データは [yfinance](https://github.com/ranaroussi/yfinance)(Yahoo Finance)から取得します。

## 機能

### 📈 銘柄分析
- ティッカー(例: `AAPL`)を入力すると2つのタブで表示。
  **⭐「既定にする」ボタンで起動時の銘柄を保存**でき、`/?ticker=NVDA` の
  URLでも直接開けます(ランキング等の「開く →」リンクと連動)。
  最近見た銘柄のクイックリンクも表示
  - **📊 チャート・指標**
    - チャート種別: ローソク足 / 平均足(Heikin-Ashi)/ ライン
    - 足の間隔: **1分 / 5分 / 15分 / 1時間** / 日足 / 週足 / 月足
      (分足は場外時間を自動除去。Yahooの無料提供範囲: 1分=直近5日、
      5分・15分=30日、1時間=1年)
    - 期間切替: 1ヶ月 / 6ヶ月 / 1年 / 5年
    - オーバーレイ: SMA(20/50/200)・EMA(20/50)・**VWAP(日中出来高加重平均)**・
      ボリンジャーバンド(±2σ)・一目均衡表(雲・転換線・基準線・遅行スパン)
    - サブチャート(自由に組合せ): 出来高(+20日平均)・RSI(14)・
      MACD(12,26,9)・ストキャスティクス(14,3,3)
    - 配当(◆)・株式分割(★)マーカー、直近値ライン、対数スケール
    - **サポート/レジスタンス自動検出(ゾーン方式)**: スイング高値/安値の
      クラスタリング(ATRベース)+出来高プロファイル+期間高値/安値から算出。
      ゾーンへの接近を**反発/突破に分類して反発実績(例: 反発9/12回=75%)を実測**し、
      時間減衰と出来高で重み付けした強さ(★1〜5)を採点。フィボナッチ・キリ番・
      SMA・ピボットとの**合流(コンフルエンス)**や**役割転換**(抵抗⇔サポート転換)も
      表に表示。チャートには半透明ゾーン+破線で描画(赤=抵抗、緑=サポート)
    - **マルチタイムフレーム合流**: 分足には日足、日足には週足、週足には月足の
      レベルを重ね、一致したレベルは「週足合流」等のタグ+強さ加点。上位足の
      強いレベル(★3以上)は表にも追加
    - **現在地アラート**: 価格がゾーン内で攻防中のとき、直近5本以内にレベルを
      ブレイクしたとき(役割転換注意)に自動表示
    - **参考指値の自動算出**: 押し目買い指値(サポートゾーン上端)・損切り目安
      (ゾーン下端−0.5ATR)・利確目安(直近抵抗ゾーン下端)・リスクリワード比に加え、
      **許容損失額から推奨株数・想定利益を計算**(投資助言ではなく機械的な参考値)
    - 高値/安値圏で片側のレベルが不足するときは、フィボナッチ拡張・ピボット・
      キリ番など**未テストの節目候補**で補完。詳細データ(ゾーン範囲・スイング数・
      反発/突破の内訳)は折りたたみ表示
    - オーバーレイに**フィボナッチ・リトレースメント**と**出来高プロファイル**
      (価格帯別出来高の横棒)も追加
    - 参考としてクラシック・ピボットポイント(P/R1-3/S1-3)も表示
    - **⚡ イベント感応度**: 決算発表・FOMCは実際のイベント日の株価変動を
      平常時と比較(イベントスタディ)、市場指数・セクターETF・米10年債金利・
      ドル指数・原油・VIXは日次リターンの相関/ベータで、イベントごとの
      影響の受けやすさを★1〜5で表に評価
    - パフォーマンス比較(S&P500 / NASDAQ総合 / ダウ平均、期間始点=100)
    - チャート上でのトレンドライン・矩形の描画ツール
    - ファンダメンタル指標(PER・PBR・ROE・配当利回り・時価総額)
    - 売上高とEPSの過去4年推移(棒グラフ)
  - **📰 ニュース・ネットの反応**
    - **アナリスト評価・イベント**: 平均目標株価(現在比)・目標レンジ・
      次回決算日(予想EPS)・レーティング分布バー・直近の格付け変更履歴
    - ニュース4ソース切替: **Yahoo Finance** / **Google News(英語)** /
      **🇯🇵 日本語ニュース**(Google News日本版) / **SEC開示**(EDGAR公式書類、
      10-K・10-Q・8-K等を日本語ラベル付きで表示)
    - SNS 3ソースの統合フィード: **Stocktwits**(投資家SNS、強気/弱気ラベル付き)、
      **Hacker News**(テック系掲示板)、**Mastodon**(分散型SNS)
    - 強気/弱気センチメント集計バー、ソース別・センチメント別フィルタ、
      **一緒に言及されている銘柄・タグの集計**(トレンドワード)
    - ※ Reddit・Bluesky はアクセスブロック、X(Twitter)は有料APIのため非対応

### ⚖️ 銘柄比較
- 最大4銘柄を並べて比較: 正規化パフォーマンスチャート(1ヶ月〜3年)と
  指標比較テーブル(リターン・年率ボラ・52週高値比・PER/PBR/ROE・
  配当利回り・時価総額・セクター)

### 🌐 市場概況
- **🌡️ 市場センチメント・買い場判定**: VIXの水準・S&P500の125日線乖離・
  50日線超セクター比率・株式と長期債のリターン差・RSIの5要素を0〜100に
  合成したFear & Greed方式の自作指数をゲージ表示。逆張りの歴史的傾向と
  長期トレンド(200日線)を組み合わせた**買い場度(★1〜5)**と解説、
  S&P500の52週高値からの調整度(高値圏/調整局面/弱気相場圏)も表示
- 指数は**過去10年のバックテストで検証済み**(重み・構成の変種を前半/後半
  分割で比較し等ウェイト構成を採用。恐怖ゾーンほど先行リターンが高い単調な
  関係を確認: 極度の恐怖後の3ヶ月平均+7.3% vs 極度の強欲後+2.4%)。
  **現在のゾーンの過去実績(平均先行リターン・勝率)を判定カードに毎日表示**
- 主要指数・為替・商品のダッシュボード: S&P500 / NASDAQ / ダウ / 日経平均 /
  ドル円 / 米10年債利回り / WTI原油 / 金 / VIX(前日比+1ヶ月ミニチャート)
- **🧭 セクター別の買い場判定**: 11セクターETFごとにRSI・対S&P500相対力・
  52週高値からの下落率を合成した買い場スコアと買い場度(★1〜5)を
  売られている順に一覧表示。11セクター×10年のプール検証でスコアが低いほど
  3ヶ月後リターンが高い単調関係を確認済み。セクター単体で逆張りが機能したかの
  実績(○/△/×)も併記(通信サービスは歴史的に不成立)
- **セクター別パフォーマンス**: 米国11セクターETF(SPDR)の前日比を色分き横棒で表示
- **⭐ ウォッチリスト**: 気になる銘柄を登録して株価・前日比をまとめて確認
  (`data/watchlist.csv` にローカル保存)
- 本日のランキング(米国市場): 値上がり率 / 値下がり率 / 出来高上位
  (Yahoo Financeスクリーナー)

### 💼 ポートフォリオ管理
- 保有銘柄(ティッカー・株数・取得単価)の登録・編集・削除
- 評価額・損益(金額・%)の一覧と合計、**円換算評価額**(ドル円レート自動取得)
- 一覧に**前日比・RSI・シグナル**(過熱/売られすぎ)列
- **銘柄別損益の棒グラフ**とセクター別配分の円グラフ
- **評価額の推移チャート**(1ヶ月〜1年、取得額ライン付き)と
  **リスク指標**(期間リターン vs S&P500・年率ボラティリティ・
  最大ドローダウン・β)
- **📅 決算カレンダー**: 保有銘柄+ウォッチリストの次回決算日・残り日数・
  予想EPSを日付順に一覧(銘柄分析へのリンク付き)
- データは `data/portfolio.csv` にローカル保存

## 必要環境

- Windows / macOS / Linux
- Python 3.10 以上

Pythonが未インストールの場合:

```powershell
winget install -e --id Python.Python.3.12
```

```bash
brew install python@3.12
```

インストール後は**新しいターミナルを開いて**から次に進んでください(PATHの反映のため)。

## セットアップ

**ランチャーが自動でセットアップします。** 初回だけ数分かかります。

- Windows: `start-app.cmd` をダブルクリック
- macOS: `start-app.command` をダブルクリック
  (初回のみ「開発元を確認できません」と出たら、右クリック →「開く」)

手動でセットアップする場合:

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

> 💡 OneDrive配下に置いている場合、`.venv` は数千個の小さいファイルを含むため
> 初回作成と同期に時間がかかることがあります(動作には影響ありません)。

## 起動方法

**いちばん簡単な方法**: ランチャーをダブルクリック。
3秒ほどでブラウザが自動で開きます。

| OS | ファイル |
|----|----------|
| Windows | `start-app.cmd`(デスクトップのショートカットも可) |
| macOS | `start-app.command` |

コマンドラインから起動する場合:

```powershell
.venv\Scripts\streamlit run app.py
```

```bash
.venv/bin/streamlit run app.py
```

起動後、ブラウザで http://localhost:8501 を開きます。
終了するにはターミナルで `Ctrl+C` を押します。

## 2台のPCで使う(GitHub同期)

このプロジェクトは https://github.com/piyohiko12/kabusikibunseki で管理しています。

**別のPCで初めて使うとき:**

```bash
git clone https://github.com/piyohiko12/kabusikibunseki.git
cd kabusikibunseki
```

あとはランチャー(`start-app.command` / `start-app.cmd`)をダブルクリックすれば、
仮想環境の作成から起動まで自動で行われます。

**日々の使い方(両方のPCで編集する場合):**

```bash
git pull          # 作業を始める前に最新を取り込む
# ...ファイルを編集...
git add -A
git commit -m "変更内容"
git push          # 作業が終わったら送る
```

> 💡 **コツ**: 作業開始時に `git pull`、終了時に `git push` を習慣にすると
> 衝突(コンフリクト)がほぼ起きません。

**同期されないもの(意図的な除外):**

| 対象 | 理由 |
|------|------|
| `data/`(保有銘柄・ウォッチリスト・既定銘柄) | **リポジトリが公開設定のため、資産情報を守る目的で除外** |
| `.venv/` | OSごとに中身が異なるため、各PCで自動作成 |
| `reports/` | ローカルの生成物 |

保有銘柄などのデータも2台で同期したい場合は、GitHubでリポジトリを
**Private に変更**してから `.gitignore` の `data/` の行を削除してください。

**任意設定**: SEC(米証券取引委員会)は公式APIの利用時に連絡先の明示を求めています。
未設定でもプロジェクトURLが送られるため動作しますが、メールアドレスを使いたい場合は
環境変数 `SEC_CONTACT` を設定するか、`data/settings.json` に
`"sec_contact": "your@email.com"` を追加してください
(このファイルはGit管理外なので公開されません)。

## 使い方

- 左サイドバーで「銘柄分析」「市場概況」「ポートフォリオ管理」を切り替えます
- **銘柄分析**: ティッカーを入力し、期間ボタンで表示範囲を切り替えます
- **市場概況**: 相場全体の地合いとランキングを確認できます
- **ポートフォリオ管理**: 表を直接編集し「保存」で確定します。
  行の追加は最下行への入力、削除は行左端のチェック→ゴミ箱アイコンで行います

## 注意事項

- データはYahoo Financeから取得しており、リアルタイムではありません(15〜20分遅延)
- 「ネットの反応」は [Stocktwits](https://stocktwits.com/)・
  [Hacker News](https://news.ycombinator.com/)・[Mastodon](https://mastodon.social/)
  の公開データ(主に英語)です
- 取得結果は15分間(財務データは24時間)キャッシュされます。短時間に大量の銘柄を
  検索するとYahoo側のレート制限で取得に失敗することがあります。その場合は
  しばらく待ってから再試行してください
- 本ツールの情報は投資判断の参考であり、正確性を保証するものではありません

## ファイル構成

```
stock-analyzer/
├── start-app.cmd          # Windows用ランチャー(ダブルクリック起動)
├── start-app.command      # macOS用ランチャー(ダブルクリック起動)
├── app.py                 # エントリポイント(ページ登録)
├── views/
│   ├── stock_analysis.py  # 銘柄分析ページ
│   ├── compare.py         # 銘柄比較ページ
│   ├── market.py          # 市場概況ページ
│   └── portfolio.py       # ポートフォリオ管理ページ
├── lib/
│   ├── data_fetcher.py    # yfinanceラッパー(st.cache_dataでキャッシュ)
│   ├── indicators.py      # テクニカル指標の計算
│   ├── levels.py          # サポート/レジスタンス検出・参考指値
│   ├── sensitivity.py     # イベント感応度の評価
│   ├── news_fetcher.py    # ニュース・SNS・SEC開示の取得
│   ├── market_mood.py     # 市場センチメント・買い場判定
│   ├── charts.py          # plotlyチャート生成
│   ├── ui.py              # チップ・バーなどのUI部品
│   ├── portfolio_store.py # ポートフォリオCSVの読み書き
│   ├── watchlist_store.py # ウォッチリストの読み書き
│   └── settings_store.py  # 既定銘柄などの設定
├── data/                  # 個人データ(自動生成・Git管理外)
├── .streamlit/config.toml # Streamlit設定
└── requirements.txt
```
