# 米国株式分析ツール

Streamlit製の米国株分析ダッシュボードです。最新価格・板情報・歩み値は
[moomoo OpenAPI](https://www.moomoo.com/ja/OpenAPI)を優先し、過去K線は明示的に有効化した場合だけ
利用枠を保護しながらmoomooを使います。チャートのフォールバック・財務・ニュース・指数などは
[yfinance](https://github.com/ranaroussi/yfinance)(Yahoo Finance)を併用します。関連先物は
Yahoo Financeの検証済み連続先物、暗号資産PERPはOKXの公開・読み取り専用APIを使います。
過去K線はmoomooの月間利用枠を確認し、取得済み銘柄やローカルキャッシュを優先します。
OpenD未起動・相場権限不足・未対応シンボル・予約枠到達時はyfinanceへ自動で戻ります。

## 機能

### 🧭 今日のトレードデスク

米国株の一日の確認順序を1ページにまとめています。

- **米国セッション時計**: 米東部時間と日本時間、プレ(04:00–09:30 ET)・
  立会(09:30–16:00 ET)・アフター(16:00–20:00 ET)・夜間(20:00–04:00 ET)を
  表示。休日・サマータイム・短縮取引にも対応し、次の立会寄付きを案内
- **市場 → 11セクター**: SPYと11セクターETFをSMA構造、20/63営業日リターン、
  SPY相対力で同じ尺度に整理し、上昇・下降・中立と採点根拠を表示
- **セクター → 代表銘柄候補**: 選択したセクターの代表4銘柄だけを遅延取得し、
  日足方向、セクター/SPY相対力、流動性、52週高値からの距離で順位付け。
  全銘柄スクリーニングやBUY保証ではありません
- **セッション別の動意**: moomoo接続時はプレ・アフター・夜間の値上がり／
  値下がり上位を表示
- **イベント予定**: FOMC・CPI・雇用統計の公式日程を常時確認でき、明示的な
  読み込み操作時だけmoomooの重要経済指標・主要決算カレンダーも表示
- 市場・セクター履歴はYahoo Finance、moomooは最新snapshotとカレンダーだけを
  使用するため、**moomooの過去K線利用枠を消費しません**

### 📈 銘柄分析
- ティッカー(例: `AAPL`)を入力すると6つのタブで表示。
  **⭐「既定にする」ボタンで起動時の銘柄を保存**でき、`/?ticker=NVDA` の
  URLでも直接開けます(ランキング等の「開く →」リンクと連動)。
  最近見た銘柄のクイックリンクも表示
- **🎯 売買情報サマリー**: ページ上部で「未保有なら」と「ロング保有中なら」を
  同時に表示し、買い・見送り・待機、保有継続・利益確定・リスク退出を混同せず確認。
  参考現在値、当日方向、日足レジーム、確定終値基準のストップ・目標・R:R、
  ★3以上の支持抵抗、安全ゲート、次回イベントと寄付き参考診断を一画面に集約します。
  この銘柄に登録済みの有効アラート件数と、画面更新時点で成立している件数も表示します
  （アプリを閉じている間のバックグラウンド監視ではありません）。
  詳細判定画面と同じアクティブルール・確定日足・182日支持抵抗を使い、表示期間を
  変えても判定基準が変わりません。既に取得した日足を再利用するため、このまとめの
  追加表示では**moomooの過去K線利用枠を追加消費しません**
  - **🧭 今日の判断**
    - プレ・立会・アフター・夜間の価格と前日終値比を横並び表示。moomoo
      snapshotがないセッションを確定終値で補完せず、欠損として明示
    - 当日始値・平均価格・前日終値・当日レンジ位置から、その日の上昇／下降／
      もみ合いを4つの観測点で説明。リアルタイムか確定日足かも表示
    - 既存の支持抵抗検出から★3以上の最寄り支持帯・抵抗帯と上下余地比を抜粋
    - 次の立会・プレ・アフター・夜間開始について、実測ギャップ、指数先物、
      SPY/QQQ、5日モメンタム、相対出来高を固定重みで合成した
      **上向き／下向き参考確率**を表示。特徴量の値・鮮度・重み・寄与を開示し、
      入力不足や取引可否不明時は確率を出しません
    - 決算・FOMC・CPI・雇用統計・重要ニュースについて、影響の受けやすさを
      **従来の★1〜5**で比較。過去実測が3件以上なら平常時に対する変動倍率を
      優先し、不足時だけ「イベント種類別の目安」と明記します。日程・影響度・
      過去反応は日本語カードで表示し、英語原文と出典は詳細欄へ分離。上振れ／
      下振れ／乱高下の条件付きシナリオも確認できます。イベントは売買点数へ
      自動加点しません
    - 参考確率は学習済み・統計的に校正済みの勝率ではありません。初期版の
      透明なヒューリスティックで、実績蓄積後にウォークフォワード検証します
  - **📊 チャート・指標**
    - **ハイブリッドデータ取得**: 最新価格はmoomoo OpenAPIを優先し、
      接続できない場合は画面に理由を表示してyfinanceへ自動フォールバック。
      ローソク足は既定でYahoo Finance(moomooの履歴K線はクォータを消費するため。
      サイドバーの設定で明示的にmoomooへ切り替えられます)
    - **moomoo板情報**: 設定から読み取り専用の売買気配を最大10段表示
      (OpenD・相場権限が利用できる場合。注文機能はありません)
    - **moomooスタイルの高機能チャート**:
      - チャート種別: ローソク足 / 平均足(Heikin-Ashi)/ OHLCバー /
        ライン / エリア
      - 分析プリセット: 標準 / デイトレ / スイング / 長期
      - クロスヘア、スクロールズーム、パン、ダブルクリックリセット
      - トレンドライン / 自由パス / 閉じたパス / 円 / 矩形の描画と消去
      - ダーク / ライトテーマ、上昇・下落色の反転、現在値ライン、対数軸
      - 期間ショートカット / スライダー、マルチタイムフレーム2画面
    - 足の間隔: **1分 / 5分 / 15分 / 1時間** / 日足 / 週足 / 月足
      (米国株の分足は通常取引時間に統一。取得量は1分=直近5日、
      5分・15分=30日、1時間=1年に制限)
    - 期間切替: 1ヶ月 / 6ヶ月 / 1年 / 5年
    - **分析プリセット**(標準 / デイトレ / スイング / 長期)で足の間隔・
      チャート種別・指標をワンクリック切替。個別に変更した内容も含めて
      **設定は保存され、次回起動時も同じ見た目で開く**
    - **十字カーソル**で価格と日付を読み取り、チャートの高さも5段階で調整可能
    - オーバーレイ: SMA(3本)・EMA(2本)・**VWAP(日中出来高加重平均)**・
      ボリンジャーバンド(±2σ)・一目均衡表(雲・転換線・基準線・遅行スパン)
      (移動平均、BOLL、RSI、MACD、STOCH、出来高MAの期間を画面で編集可能)
    - サブチャート(自由に組合せ): 出来高(+期間編集可能な平均線)・RSI・
      MACD(12,26,9)・ストキャスティクス(14,3,3)
    - MACDクロス / RSI閾値通過のテクニカルイベント表示(オプション)
    - 配当(◆)・株式分割(★)マーカー、直近値ライン、対数スケール
    - **サポート/レジスタンス自動検出(ゾーン方式)**: スイング高値/安値の
      クラスタリング(ATRベース)+出来高プロファイル+期間高値/安値から算出。
      ゾーンへの接近を**「ヒゲ拒絶」「反発」「突破」に分類して実測**する
      (実体では入らずヒゲだけ刺さって押し戻された接触=拒絶は反発の強い証拠として重く採点)。
      ゾーン内で実際に商われた出来高、時間減衰、出来高比で重み付けし、
      直近に実体で破られたレベルは減点。強さ(★1〜5)は
      **S&P500・505銘柄の実データでウォークフォワード検証して較正済み**
      (下記「★の意味と限界」参照)。フィボナッチ・キリ番・
      SMA・ピボットとの**合流(コンフルエンス)**や**役割転換**(抵抗⇔サポート転換)も
      表に表示。チャートには半透明ゾーン+破線で描画(赤=抵抗、緑=サポート)
    - **マルチタイムフレーム合流**: 分足には日足、日足には週足、週足には月足の
      レベルを重ね、一致したレベルは「週足合流」等のタグ+強さ加点。上位足の
      強いレベル(★3以上)は表にも追加
    - **現在地アラート**: 価格がゾーン内で攻防中のとき、直近5本以内にレベルを
      ブレイクしたとき(役割転換注意)に自動表示
    - **moomooデータによるAI再評価**: ボタンを押すとmoomoo OpenAPIの板の厚み・
      直近約定の買売偏り・大口/中口/小口の当日資金フローを取得し、基礎レベルを
      ライブ需給で再採点。変更前の基礎★、再評価★、0〜100点、信頼度、根拠を
      比較してから「適用/却下」を選べます。既存ゾーンと重ならない非常に厚い板は
      一時候補として提案し、足・期間・最新バーが変わると古い評価を持ち越しません
    - **参考指値の自動算出**: 押し目買い指値(サポートゾーン上端)・損切り目安
      (ゾーン下端−0.5ATR)・利確目安(直近抵抗ゾーン下端)・リスクリワード比に加え、
      **許容損失額から推奨株数・想定利益を計算**(投資助言ではなく機械的な参考値)
    - 高値/安値圏で片側のレベルが不足するときは、フィボナッチ拡張・ピボット・
      キリ番など**未テストの節目候補**で補完。詳細データ(ゾーン範囲・スイング数・
      反発/突破の内訳)は折りたたみ表示
    - オーバーレイに**フィボナッチ・リトレースメント**と**出来高プロファイル**
      (価格帯別出来高の横棒)も追加
    - 参考としてクラシック・ピボットポイント(P/R1-3/S1-3)も表示
    - **⚡ イベント感応度**: 決算発表・FOMCは実際のイベント日の株価変動を
      平常時と比較(イベントスタディ)、市場指数・セクターETF・米10年債金利・
      ドル指数・原油・VIXは日次リターンの相関/ベータで、イベントごとの
      影響の受けやすさを★1〜5で表に評価
    - パフォーマンス比較(S&P500 / NASDAQ総合 / ダウ平均、期間始点=100)
    - チャート上でのトレンドライン・矩形の描画ツール
    - ファンダメンタル指標(PER・PBR・ROE・配当利回り・時価総額)
    - 売上高とEPSの過去4年推移(棒グラフ)
  - **🌐 先物・PERP**（「読み込む / 更新」を押したときだけ取得）
    - セクター・業種から関連性の高い先物を最大3本提案。S&P 500、NASDAQ、
      Russell 2000、米国債、原油、天然ガス、金、銅などの検証済み連続先物を、
      商品別の価格桁・単位付きで選択可能
    - 対象株と先物を共通期間・共通始点=100で比較し、日次リターンの20日・60日相関、
      60日ベータ、20日・60日の相関符号一致を表示
    - BTC / ETH / SOL / XRP / DOGEのOKX USDT無期限先物を、Mark価格、24時間騰落、
      Funding premium、Funding rateと次回時刻、単純年率換算、建玉、出来高で表示
    - PERPは株式そのものの先物・直接ヘッジではありません。暗号資産関連株だけを
      ホワイトリストで区別し、その他は市場全体のリスク選好の参考として表示
    - 先物・PERPは売買判定の点数、アラート、注文に使用しません。Yahoo先物と
      OKX公開APIはmoomooの過去K線利用枠を消費せず、APIキーも不要です
  - **🔬 板・歩み値**(moomoo連携時のみ。下記「moomoo連携」参照)
    - 板情報(気配)の横棒表示、スプレッド・買い板の厚み
    - 歩み値(直近の約定)と買い/売り約定の比率、大口/中口/小口の資金流入
  - **🏦 需給・IV**(moomoo連携時のみ)
    - **空売り残高**の推移: 空売り株数・浮動株に対する比率・買い戻しにかかる日数
      (days to cover。高いほど踏み上げが起きやすい)
    - **機関投資家の保有推移**: 保有機関数・保有株数・保有比率と各増減
      (13F等の四半期報告ベース)
    - **オプションのIV / HV**: 予想変動率と実績変動率の推移、IVプレミアム、
      moomooによる状態判定コメント
  - **📰 ニュース・ネットの反応**
    - **アナリスト評価・イベント**: 平均目標株価(現在比)・目標レンジ・
      次回決算日(予想EPS)・レーティング分布バー・直近の格付け変更履歴
    - ニュース4ソース切替: **Yahoo Finance** / **Google News(英語)** /
      **🇯🇵 日本語ニュース**(Google News日本版) / **SEC開示**(EDGAR公式書類、
      10-K・10-Q・8-K等を日本語ラベル付きで表示)
    - SNS 3ソースの統合フィード: **Stocktwits**(投資家SNS、強気/弱気ラベル付き)、
      **Hacker News**(テック系掲示板)、**Mastodon**(分散型SNS)
    - 強気/弱気センチメント集計バー、ソース別・センチメント別フィルタ、
      **一緒に言及されている銘柄・タグの集計**(トレンドワード)
    - ※ Reddit・Bluesky はアクセスブロック、X(Twitter)は有料APIのため非対応

### ⚖️ 銘柄比較
- 最大4銘柄を並べて比較: 正規化パフォーマンスチャート(1ヶ月〜3年)と
  指標比較テーブル(リターン・年率ボラ・52週高値比・PER/PBR/ROE・
  配当利回り・時価総額・セクター)

### 🌐 市場概況
- **🌡️ 市場センチメント・買い場判定**: VIXの水準・S&P500の125日線乖離・
  50日線超セクター比率・株式と長期債のリターン差・RSIの5要素を0〜100に
  合成したFear & Greed方式の自作指数をゲージ表示。逆張りの歴史的傾向と
  長期トレンド(200日線)を組み合わせた**買い場度(★1〜5)**と解説、
  S&P500の52週高値からの調整度(高値圏/調整局面/弱気相場圏)も表示
- 指数は**過去10年のバックテストで検証済み**(重み・構成の変種を前半/後半
  分割で比較し等ウェイト構成を採用。恐怖ゾーンほど先行リターンが高い単調な
  関係を確認: 極度の恐怖後の3ヶ月平均+7.3% vs 極度の強欲後+2.4%)。
  **現在のゾーンの過去実績(平均先行リターン・勝率)を判定カードに毎日表示**
- 主要指数・為替・商品のダッシュボード: S&P500 / NASDAQ / ダウ / 日経平均 /
  ドル円 / 米10年債利回り / WTI原油 / 金 / VIX(前日比+1ヶ月ミニチャート)
- **🧭 セクター別の買い場判定**: 11セクターETFごとにRSI・対S&P500相対力・
  52週高値からの下落率を合成した買い場スコアと買い場度(★1〜5)を
  売られている順に一覧表示。11セクター×10年のプール検証でスコアが低いほど
  3ヶ月後リターンが高い単調関係を確認済み。セクター単体で逆張りが機能したかの
  実績(○/△/×)も併記(通信サービスは歴史的に不成立)
- **セクター別パフォーマンス**: 米国11セクターETF(SPDR)の前日比を色分き横棒で表示
- **⭐ ウォッチリスト**: 気になる銘柄を登録して株価・前日比をまとめて確認
  (`data/watchlist.csv` にローカル保存)
- 本日のランキング(米国市場): 値上がり率 / 値下がり率 / 出来高上位
  (Yahoo Financeスクリーナー)
- **🕒 時間外のランキング**(moomoo連携時のみ): プレマーケット / アフターマーケット /
  夜間取引それぞれの値上がり・値下がり上位。Yahoo Financeでは取得できません
- **🏛️ 金融政策とオプション市場の織り込み**(moomoo連携時のみ):
  FedWatchのFOMC会合別・政策金利レンジ別の**織り込み確率**と、
  米国株オプション市場の**Put/Callレシオ**の推移(1.0超で弱気寄り)

### 🎯 売買判定・アラート(判定表示のみ・発注機能なし)

**① 判定** — 確定した日足だけを使い、「新規ロング」と「保有中ロング」を分けて
判定します。保有中はさらに**利益確定**と**リスク退出**を分離し、リスク退出を優先します。
空売り判定や注文実行は行いません。条件ごとに「必要な値・実測値・成立状況・配点」を
並べ、相関グループの上限適用前後も追えます。ウォッチリストの一括判定は、未取得銘柄の
moomoo過去K線枠を消費せず、キャッシュまたはYahoo Financeを使います。

**② 判定基準の設定** — 判定に使う条件を自由に組み立てられます。

- **28種類の指標**から選択: RSIの水準/変化・SMA構造/傾き・MACDの水準/改善・
  反転足・20日ブレイク・ストキャスティクス・ボリンジャー%B・出来高・
  1/5/20日リターン・52週下落率・ATR・年率ボラティリティ・
  サポート/レジスタンスの距離/強度・リスクリワードなど
- 各条件に **比較演算子(以上/以下)・しきい値・配点** を設定
- 各条件を**必須条件**に指定可能。必要なデータが欠けた場合は弱気と決めつけず
  `WAIT`にし、流動性・確定足・鮮度・スプレッド・決算前後も安全ゲートとして確認
- 相場を上昇/下降トレンド・レンジ・高ボラに分類し、ルールを使うレジームを限定
- トレンド・モメンタム・価格帯・出来高・リスクの**相関グループごとに配点上限**を設定
- **新規ロング・利益確定・リスク退出を別々に**定義し、それぞれ合格点を設定
- 固定%ではなくATRと強い支持抵抗から参考ストップ/目標/R:Rを算出
- ルールは名前を付けて**いくつでも保存**でき、複製して派生も作れます
  (`data/rules.json` にローカル保存)
- 既定で「押し目買い」「順張り」「逆張り」の3つを用意
- 合格点0、成立不能、相関した指標の重複、矛盾などを検査し、問題がある間は保存を無効化
- 旧既定ルールは安全なv2既定値へ自動移行。利用者が編集した旧ルールは条件と配点を保持

**③ 時系列検証** — 読み込んだ確定日足だけでウォークフォワード診断を行います。
各判定日で過去データだけから支持抵抗を再計算し、翌営業日始値での約定、手数料、
スリッページ、ATRストップ/目標、最大保有日数を反映します。検証用の銘柄取得では
新しいmoomoo過去K線枠を消費しません。結果は勝率・Profit Factor・期待値・最大ドローダウン・
区間別成績として表示します。Profit Factorは銘柄の価格水準に偏らないよう純損益率で計算します。
決算日、当時のスプレッド・板・資金フローは履歴検証に含まず、現在判定のゲートだけに使います。

**④ アラート** — 価格やRSIの節目に達したら画面で知らせます。

- 価格が上回る/下回る・前日比・RSI・サポート/レジスタンスへの接近・
  ルールが新規買い/利益確定/リスク退出になる条件
- 価格と前日比はmoomooのリアルタイムスナップショットがあれば優先
- 銘柄ごとに複数登録でき、個別に有効/無効を切り替えられます
  (`data/alerts.json` にローカル保存)
- 開いている間、1〜5分間隔で自動再判定できます

> ⚠️ **アラートはアプリを開いている間だけ動きます。** ブラウザを閉じている間の
> 監視、メールやスマートフォンへの通知はできません(Streamlitはアクセスされた
> ときだけ動作する仕組みのため)。
>
> ウォークフォワード診断は設定の弱点を見つけるための機能であり、将来の有効性を
> 証明するものではありません。点数は上昇確率でも期待利益でもありません。

## 🧱 サポート/レジスタンスの「★」の意味と限界

★はS&P500構成銘柄505社・2013〜2018年の日次データを使った
**ウォークフォワード検証**で較正しています。6ヶ月分のデータからレベルを算出し、
40本先までに価格がそのゾーンへ接近したとき反発したか突破したかを実測しました。

**較正に使っていない80銘柄での結果:**

| 強さ | 接近後に反発した割合 | 該当レベルの割合 |
|------|---------------------|-----------------|
| ★5 | 65.0% | 20.8% |
| ★4 | 58.0% | 20.9% |
| ★3 | 60.2% | 21.8% |
| ★2 | 57.6% | 16.4% |
| ★1 | 58.9% | 20.1% |

★5は★1より約6pt反発しやすい、という程度の差です。★4以下の差はほとんどありません。

> ⚠️ **もっと重要な限界**: 検証では、**同じ距離にランダムに引いた線と比べた
> 反発率の差はほぼゼロ**でした(距離帯で層別して比較)。
> つまり「レベルに触れたあと反発するか抜けるか」は、この手法では予測できていません。
>
> ★は**レベル同士の優劣を並べるための相対評価**として使ってください。
> 「相対的に注目度が高い価格帯」を示すものであり、売買判断の根拠にはなりません。

以前のバージョンは強さの計算式は同じでも★への変換が飽和しており、
全レベルの約7割が★5になっていました。その状態では★1と★5の反発率が
むしろ逆転(-2.1pt)しており、★に情報がありませんでした。

## 🔬 moomoo連携(任意・無料)

moomoo証券の **moomoo OpenAPI** に接続すると、Yahoo Financeでは取れない情報が使えます。
**既定はオフ**で、接続しなくてもツールは従来どおり動きます。

| 追加されるもの | 内容 |
|----------------|------|
| リアルタイム株価 | Yahooの15〜20分遅延が解消。銘柄分析の現在値・前日比が即時値になる |
| セッション別価格 | プレ・立会・アフター・夜間のsnapshotを「今日の判断」に表示。欠損は推測しない |
| 経済指標・決算カレンダー | トレードデスクで明示的に読み込んだ時だけ、今週の高影響イベントを表示 |
| 🔬 板・歩み値タブ | 板情報(気配)とスプレッド・板の厚み、直近の約定履歴(歩み値)と買い/売りの比率 |
| 資金流入 | 大口/中口/小口ごとの本日の純流入。機関投資家の動きの参考になる |
| 支持線・抵抗線の再評価 | 板・歩み値・資金流入で更新候補を作り、変更前後と根拠を確認して適用 |
| 🏦 需給・IVタブ | 空売り残高、機関投資家の保有推移、オプションのIV/HV |
| 🕒 時間外ランキング | プレ/アフター/夜間の値上がり・値下がり上位(市場概況) |
| 🏛️ FOMC織り込み・Put/Call | FedWatchの利上げ/利下げ確率とPut/Callレシオ(市場概況) |

### 安全性について

- **発注は一切しません。** 相場用の `OpenQuoteContext` のみを使い、発注に使う
  取引用コンテキストはコード内のどこからも参照していません。
  したがって不具合や誤操作で注文が出ることは原理的に起こりません
- **パスワードをこのリポジトリで扱いません。** ログインはOpenD側で完結するため、
  公開リポジトリに認証情報が入る余地がありません
- 接続先は既定でローカル(`127.0.0.1:11111`)のみ

### 使い方

1. moomoo証券の口座でログインできる **moomoo OpenD** をPCにインストールして起動
   (macOS/Windows対応。[ダウンロード](https://www.moomoo.com/ja/download/OpenAPI))
2. アプリのサイドバー →「moomooリアルタイム連携」→「有効にする」

OpenDが起動していないときは、サイドバーに理由が表示され、
自動的にYahoo Financeでの表示に戻ります。

> ⚠️ 板情報などは口座の相場権限に依存します。権限が無い項目は
> 「取得できませんでした」と表示されます(アプリは落ちません)。
> 履歴K線には口座ごとの取得上限(クォータ)があります。取得前に
> `get_history_kl_quota(get_detail=True)` で残数と過去30日間の取得銘柄を確認し、
> 既定では過去K線をYahoo Financeから取得します。サイドバーの
> 「過去K線もmoomooを使用（枠保護あり）」をオンにした場合も、同じ銘柄の再取得と
> 足種別ローカルキャッシュを優先します。分足は数分、日足は5分、週足・月足はより長く
> 再利用し、短期チャートを24時間固定しません。未取得銘柄は明示的な単一銘柄表示でのみ
> 取得対象になり、残数が「履歴K線の予約枠」以下ならYahoo Financeへ切り替えます。
> ウォッチリスト・アラート・時系列検証は新しい枠を消費しません。取得不能時は期限切れ
> キャッシュも復旧用に利用します。

## 注意事項

- moomoo利用時のリアルタイム性・板の段数は契約中の相場権限に依存します。
  yfinanceへフォールバックした場合はリアルタイムではありません(通常15〜20分遅延)
- 米国株の各セッション時刻は
  [moomoo公式の米国株取引時間](https://www.moomoo.com/us/support/topic4_44)と
  [24時間取引の説明](https://www.moomoo.com/us/support/topic4_664)を基準にしています。
  夜間・24時間取引は対象銘柄のみで、時間外は流動性とスプレッドが立会時間と異なります
- 「寄付き参考確率」は固定重みの未校正値で、統計的な勝率ではありません。
  2つ以上の鮮度ある方向特徴がない場合や夜間対象可否が不明な場合は表示しません
- 関連先物はYahoo Financeの連続先物で、実限月・清算値・取引所公式配信とは異なります。
  ロール時には価格差の影響を受ける場合があります。PERPはOKX公開APIのMark価格を主表示し、
  Fundingの単純年率換算は予測ではありません。いずれも読み取り専用です
- 「ネットの反応」は [Stocktwits](https://stocktwits.com/)・
  [Hacker News](https://news.ycombinator.com/)・[Mastodon](https://mastodon.social/)
  の公開データ(主に英語)です
- 株価履歴などの取得結果は主に15分間(財務データは24時間)、関連先物は300秒、
  PERPは60秒キャッシュされます。「読み込む / 更新」で対象だけを更新できます。短時間に大量の銘柄を
  検索するとYahoo側のレート制限で取得に失敗することがあります。その場合は
  しばらく待ってから再試行してください
- 本ツールの情報は投資判断の参考であり、正確性を保証するものではありません
